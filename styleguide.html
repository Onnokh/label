Elevation

Six named shadow recipes, each for one job. Monochromatic only — every layer is rgba(0,0,0,x) or rgba(255,255,255,x), never a colored tint. Depth is built by stacking these, not by changing surface color.

Keyboard Key

Pressable elements — keyboard-shortcut keys. An inset white top-highlight over a layered black drop creates a physical bevel that looks depressable.
rgba(0,0,0,.4) 0 1.5px .5px 2.5px, rgb(0,0,0) 0 0 .5px 1px, rgba(0,0,0,.25) 0 2px 1px 1px inset, rgba(255,255,255,.2) 0 1px 1px 1px inset

Button / Dropdown

Buttons and dropdown menus. A soft, short downward drop — lifts the control just off the surface without drama.
rgba(0,0,0,.03) 0 7px 3px 0, rgba(0,0,0,.25) 0 4px 4px 0

Outlined Highlight Card

Featured or selected cards (e.g. the Pro plan, a highlighted extension). A 0.25-opacity white outer ring makes the card appear to glow against the dark canvas.
rgba(255,255,255,.05) 0 1px 0 0 inset, rgba(255,255,255,.25) 0 0 0 1px, rgba(0,0,0,.2) 0 -1px 0 0 inset

Glass Product Card

Frosted product-window and app-UI containers. Intentionally faint — it pairs with a backdrop-blur to read as glass, so the shadow only seats the edge.
rgba(0,0,0,.28) 0 1.189px 2.377px 0

Modal / Floating Window

The highest layer — modals, the command window, floating panels. A deep 40px ambient shadow plus a hairline white top edge separates it cleanly from everything below.
rgba(0,0,0,.4) 0 4px 40px 8px, rgba(0,0,0,.8) 0 0 0 .5px, rgba(255,255,255,.3) 0 .5px 0 0 inset

Navigation Ring Link

Circular icon and nav/social links. A barely-perceptible warm bloom (not neutral black) suggests a faint light behind the element rather than a cast shadow.
rgba(215,201,175,.05) 0 0 20px 5px, rgba(215,201,175,.05) 0 0 16px -7px
