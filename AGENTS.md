# Sleevy

Sleevy is a native-first read-later app. Read [CONTEXT.md](./CONTEXT.md) before changing anything — it holds the ubiquitous language for the whole repo, and its terms are the ones to use in code, API contracts, and commit messages.

## Agent skills

### Issue tracker

Issues and specs live in the Linear project `Sleevy` (team `Plowski Inc.`, key `PLO`), reached through the executor MCP — not GitHub Issues. See [docs/agents/issue-tracker.md](./docs/agents/issue-tracker.md).

### Domain docs

Single-context: one [CONTEXT.md](./CONTEXT.md) at the repo root, with decisions recorded as ADRs in [docs/adr](./docs/adr) and delivery plans in [docs/implementation](./docs/implementation). Respect the ADRs covering any area being changed, and add new vocabulary to CONTEXT.md rather than inventing synonyms.
